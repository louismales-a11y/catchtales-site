## CapCut Workflow
1. Import photos from `images/solunar-video/`
2. Import audio from `audio/solunar/`
3. Each photo = 1 slide at specified duration
4. Add catchtales-logo-video.png watermark top-left on all slides (2x size, clamp 72-108px)
5. Add fade transitions (0.3s)
6. Add text overlays per notes above (green = #76FF03, cyan = #00BCD4)
7. Export at 1080p, 30fps, MP4
